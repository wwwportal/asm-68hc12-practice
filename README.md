# asm-68hc12-practice

A collection of small 68HC12/68HCS12 assembly exercises from a processor architecture course, kept together since none is substantial enough to stand alone. (Multisim circuit simulation files and lab handouts from the same course were left out — they're not code.)

- `AddSubtractValues` — adds and subtracts stored byte values
- `FlashPB7` — flashes a pin via port B
- `SwitchItUp` — reads switch input and drives LEDs
- `IndexedAddressingExercise` — indexed addressing practice
- `BCDCounter` — a BCD counter
- `ReverseArray` — reverses an array
- `BCDAddition` — adds two BCD values
- `AddressingModesPractice` — addressing modes practice, including a stack/array exercise (Q3)
- `StackAndArrayPractice` — array indexing exercise using indexed addressing
- `BranchInstructionExamples` — course-provided branch instruction (BEQ/BNE) examples
- `ArrayIterationExamples` — course-provided array iteration examples, including reading an array from an included file
